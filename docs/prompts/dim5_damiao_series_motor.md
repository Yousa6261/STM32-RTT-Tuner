# 提示词：维度五 - 达妙全系列电机通用看板与专属监控

## 任务目标
打造通用于**达妙（Damiao）全系列无刷电机**（包括 DM4310、DM4340、DM6006、DM8006、DM8009 等）的参数化通用控制、遥测诊断与维护面板。基于标准达妙 CAN / FDCAN 通信协议，实现 MIT 模式、速度模式、位置模式动态切换、多电机 ID 轮询、零位一键标定及驱动器健康监控。

---

## 1. 单片机 FDCAN 通用驱动解耦与多电机管理
1. **电机参数泛化结构定义 (`dm_motor.c / .h`)**：
   - 建立达妙全系列参数宏定义与结构体，支持根据型号自动匹配极限值（如 $P_{\max}, V_{\max}, T_{\max}, K_{p,\max}, K_{d,\max}$）。
   - 支持多电机管理（维护电机列表，每个电机具备独立 CAN ID、Master ID、当前状态缓存）。
2. **状态报文全字段解码**：
   - 解析达妙驱动器反馈帧（8 字节 CAN 报文），提取：
     - 机械角度 / 多圈绝对位置（$P$）
     - 实时角速度（$V$）
     - 实时相电流 / 力矩（$T$）
     - MOS 管温度（$T_{\text{mos}}$）
     - 电机线圈/转子温度（$T_{\text{rotor}}$）
     - 错误代码（过压、欠压、过流、堵转、过温、编码器故障）
3. **控制模式协议封装**：
   - **MIT 模式帧打包**：将目标位置 $P_{\text{des}}$、目标速度 $V_{\text{des}}$、刚度 $K_p$、阻尼 $K_d$、前馈力矩 $T_{\text{ff}}$ 线性映射打包为 8 字节指令。
   - **速度模式帧打包** / **位置模式帧打包**。
   - **电机指令集**：使能电机 (`0xFF...0xFC`)、失能电机 (`0xFF...0xFD`)、保存当前位置为机械零点 (`0xFF...0xFE`)、清除故障标志。
4. **RTT 遥测打通**：
   - 在主循环或定时器中通过 RTT 上报电机完整状态流（如 `$DATA:id=1,pos=...,vel=...,tor=...,t_mos=...,err=...`）。

---

## 2. Web UI 达妙电机通用控制与诊断工作区
1. **电机型号与通信配置卡片**：
   - 电机型号选择下拉框：【DM4310 / DM4340 / DM6006 / DM8006 / DM8009 / 自定义】（选择后自动更新滑动条行程上限和单位换算）。
   - 电机 ID 选择（支持单电机调试与多电机快速切换）。
2. **三模动态控制面板**：
   - **MIT 模式标签页**：提供 5 组独立调节滑块（$P_{\text{des}}, V_{\text{des}}, K_p, K_d, T_{\text{ff}}$），并带有预设阻尼手感测试按钮。
   - **速度模式标签页**：转速输入框 + 速度阶跃滑块。
   - **位置模式标签页**：绝对位置/多圈目标角度输入。
3. **电机健康状态看板**：
   - 实时双温监测仪表盘（MOS 温度、线圈温度，带高温预警色变）。
   - 电机电气状态仪表（母线实时电压、相电流、实际输出力矩 Nm）。
   - 错误状态告警灯（欠压、过流、过温一目了然）。
4. **运维与标定工具栏**：
   - 【⚡ 使能电机】 / 【🛑 紧急失能】（带防误触安全锁）
   - 【📍 标定当前为机械零位】（点击后单片机发送 0xFE 指令并自动回读确认）
   - 【🧹 清除电机错误】

---

## 3. 验收标准
- 网页端可灵活切换电机型号（如从 DM8009 切换到 DM4310），滑块的最大力矩与转速范围自动更新为对应型号规格。
- 在 MIT 模式下拖动 $K_p$ 和 $K_d$，电机手感发生实时变化；点击【标定机械零位】后电机当前物理位置被重置为 0。
- 电机运行过程中，网页端仪表盘能平滑显示温度、实际转速和电流，出现过温或欠压时告警指示灯立即变红。
