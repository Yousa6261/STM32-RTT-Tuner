# 提示词：维度一 - 参数闭环持久化与预设管理

## 任务目标
为 STM32H723 + RTT 调参系统增加参数掉电持久化（Flash 模拟 EEPROM）以及上位机多方案预设配置文件（JSON 导入导出）管理功能，确保调好的参数断电不丢失，并可方便地在不同工况间切换。

---

## 1. 单片机固件端（STM32H723）开发要求
1. **Flash 存储管理模块 (`flash_storage.c / .h`)**：
   - 使用片内 Flash 最后一个扇区（Bank 1 Sector 7，起始地址 `0x080E0000`，扇区大小 128KB）作为参数持久化存储区。
   - 定义参数存储帧结构体，包含：
     - Magic Number 头部标识（如 `0x53544D32`）
     - 参数表结构版本号（`version`）
     - 参数数量（`param_count`）
     - 参数键值对列表（参数名 Hash/字符串 + 当前值）
     - CRC32 校验和
   - 提供写入接口：`bool Flash_Save_Params(void)`，写入前安全擦除该扇区，通过 Flash 编程接口写入并校验。
   - 提供读取接口：`bool Flash_Load_Params(void)`，校验 Magic 和 CRC32，校验成功后自动更新 RAM 中的变量。
2. **RTT 指令协议扩展 (`rtt_param_parser.c / .h`)**：
   - 新增 `$SAVE` 指令：单片机执行 Flash 写入，成功回复 `$ACK:SAVE:OK`，失败回复 `$ACK:SAVE:ERR:<原因>`。
   - 新增 `$RESET:PARAMS` 指令：单片机将参数恢复至代码出厂初始值，并回传 `$ACK:RESET:OK`。
   - 系统开机初始化（`main.c` 中的 `RTT_Param_Init()` 之后）自动调用 `Flash_Load_Params()`，若存在有效参数则自动覆盖默认值。

---

## 2. 上位机与 Web UI 端开发要求
1. **顶部操作栏新增控制按钮**：
   - 新增【💾 保存到 Flash】按钮：点击后发送 `$SAVE`，收到确认后弹出“参数已成功持久化至单片机 Flash”提示。
   - 新增【🔄 恢复出厂】按钮：点击后二次确认，发送 `$RESET:PARAMS` 并自动触发 `$GET:ALL` 刷新全界面滑块。
2. **参数配置方案预设管理器（Profiles）**：
   - 新增【方案导出】按钮：将当前界面所有参数的名、当前值、最小值、最大值导出为本地 `.json` 配置文件（如 `motor_no_load.json`）。
   - 新增【方案导入】按钮：选择本地 `.json` 文件导入，前端自动完成字段匹配与范围校验，更新页面滑块并批量下发 `$SET` 指令到单片机。
   - 内置快速预设下拉选择框（如：方案A-平稳响应、方案B-极速响应、方案C-抗扰防震）。

---

## 3. 验收标准
- 在网页上调节 PID 参数后，点击【保存到 Flash】，单片机断电重启后，在网页点击刷新，读取到的参数依然是断电前保存的值。
- 导出当前配置并在界面随意修改参数后，导入之前导出的 JSON，参数能全部无缝恢复。
