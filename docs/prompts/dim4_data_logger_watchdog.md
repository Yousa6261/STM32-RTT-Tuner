# 提示词：维度四 - 实验数据黑匣子与热插拔自愈

## 任务目标
为系统增强高可靠性与科研工程实用性：打造微秒级高保真实验数据黑匣子录制与导出机制（CSV / MATLAB .mat 格式），并引入硬件热插拔状态看门狗，实现 USB 调试线断开或单片机断电后的静默等待与无感自动重连。

---

## 1. 实验数据黑匣子录制引擎 (Data Logger)
1. **服务端与前端录制管道**：
   - 网页端新增悬浮【🔴 开始录制】/【⏹ 停止录制】控制条，带录制时长与已捕获点数实时计数。
   - 每条捕获记录包含：
     - 高精度时间戳（以微秒或毫秒为单位的时间轴相对偏移）
     - 所有监测通道的实时数值（如目标转速、实际转速、母线电流、力矩、电机温度等）
2. **多格式高保真导出**：
   - **标准 CSV 格式导出**：包含标准列头，第一行为通道标识符，支持用 Excel 或 Python Pandas 直接读取分析。
   - **MATLAB 兼容格式**：格式化为符合 MATLAB `timeseries` 对象的结构化数据文件，便于直接载入 Simulink 进行控制系统建模与辨识。
   - 自动生成实验元数据报告（记录本次实验时间、调参者、当前单片机固件版本及最终 PID 参数）。

---

## 2. 硬件链路看门狗与热插拔自愈 (Auto-Recovery Watchdog)
1. **链路状态心跳机制**：
   - Python 后端每秒对 OpenOCD 进程及底层 DAP-Link / CMSIS-DAP 调试器状态进行非侵入式健康探测。
   - 当检测到单片机意外断电、复位或 USB 调试器被拔出时：
     - 安全挂起内部数据分发任务，避免产生异常溢出崩溃。
     - 网页端状态指示灯变为【🟡 链路断开，正在等待硬件重连...】。
2. **自动无感重新握手**：
   - 当检测到调试器重新接入并检测到目标 SWD 链路时，后端自动重构 OpenOCD 实例与 RTT 端口连接。
   - 链路重连成功后，自动向单片机拉取最新参数状态，网页端状态灯恢复【🟢 正常连接】，无需用户手动刷新网页或重新运行命令行。

---

## 3. 验收标准
- 启动录制 30 秒，点击停止后可顺利下载规范的 `.csv` 文件，文件内容时间轴无丢失、无时间错位。
- 在系统正常调参运行时强行拔掉 DAP-Link 调试器 USB 线，网页端准确显示断线等待提示且 Python 后台不崩溃；重新插回 USB 线后 2 秒内系统自动恢复通信与调参。
