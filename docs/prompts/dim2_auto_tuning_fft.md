# 提示词：维度二 - 自动化调参与性能辨识

## 任务目标
构建“阶跃激励自动注入 + 控制指标自动计算 + 实时 FFT 频谱共振辨识”闭环系统。利用上位机驱动单片机执行标准化阶跃响应测试，自动计算超调量、上升时间、调节时间及稳态误差，并通过频域分析指导电机滤波参数设定。

---

## 1. 阶跃响应自动化测试套件
1. **测试控制面板（Web UI）**：
   - 支持配置阶跃测试参数：
     - 测试目标参数（如 `target_speed`）
     - 起始值（如 `0 RPM`）与 阶跃目标值（如 `2000 RPM`）
     - 阶跃持续时间（如 `1500 ms`）与 稳态阈值误差带（默认 $\pm 2\%$ 或 $\pm 5\%$）
   - 一键启动按钮【🚀 开始阶跃评估】：
     - 自动向单片机下发初始值 -> 延时稳定 -> 突变目标值下发阶跃指令。
     - 同时启动高频遥测捕获，记录从触发瞬间起的真实响应曲线。
2. **控制工程关键指标自动计算算法（前端 JS）**：
   - **超调量 $\sigma\%$**：自动检索波形峰值 $y_{\max}$，计算 $\frac{y_{\max} - y_{\text{target}}}{y_{\text{target}}} \times 100\%$。
   - **上升时间 $t_r$**：响应值从 $10\%$ 上升至 $90\%$ 目标值所需时间。
   - **峰值时间 $t_p$**：达到第一个峰值所需的时间。
   - **调节时间 $t_s$**：响应曲线最终进入设定误差带（如 $\pm 2\%$）且不再溢出的时刻。
   - **稳态误差 $e_{ss}$**：稳定区间的实际平均值与目标值的绝对差值。
   - 在图表上直观渲染辅助虚线（10%、90%、目标基准线、误差带、调节时间标记点），并生成指标评估总结卡片。

---

## 2. 频域分析与机械共振辨识（FFT 分析仪）
1. **轻量级 FFT 运算引擎**：
   - 提取最新 512 或 1024 个采样点的反馈波形（如实际转速或母线电流）。
   - 在前端（或通过 Web Worker）执行快速傅里叶变换（FFT），计算幅频响应曲线。
2. **共振点自动锁定与显示**：
   - 在图表下方显示频谱图（横轴：频率 Hz，纵轴：幅值 dB）。
   - 自动标出最大尖峰共振频率点（如 $f_{\text{res}} = 430\text{ Hz}$）。
   - 给出专家建议提示（如“检测到 430Hz 机械共振，建议配置二阶陷波滤波器中心频率为 430Hz”）。

---

## 3. 验收标准
- 点击【开始阶跃评估】后，电机自动执行阶跃响应，网页图表完整捕获过程并在测试结束后 0.5 秒内自动计算出超调量、调节时间等 4 项核心指标。
- 在电机震动或变频运行时，频谱图能够实时显示清晰的频峰与主频频率。
